      Naming guide

      Layers are matched by name: knob, dial, fader, slider, button, switch, pad, menu, display, screen, vu, meter, keyboard, xy pad, mod wheel, label, line (→ guide), bar, area (→ shape).

      Add a tag to be explicit: Cutoff [knob-primary], Logo [image], Notes [skip]. Knob size picks the tier: ≥80px hero, ≥44px knob, smaller = mini.

      A studio panel's art is never read as controls; it becomes the background image.
