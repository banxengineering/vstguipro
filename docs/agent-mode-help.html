Agent mode

Paste a sketch or screenshot into Claude Code or Codex. Your agent builds the plugin UI in Figma, takes changes in plain words, and exports it ready for JUCE, HISE or your own code.

You need VST GUI Pro with PRO, the Figma desktop app, Claude Code or Codex, and Node.js 18 or newer.

Install

Paste this into Claude Code or Codex:

Install vstgui-mcp from https://www.npmjs.com/package/vstgui-mcp

Restart your agent when it's done and approve vstgui when asked. Then open VST GUI Pro in Figma and click Agent.

Install by hand instead

Claude Code: put this in .mcp.json in your project folder. On Windows, use "command": "cmd" and "args": ["/c", "npx", "-y", "vstgui-mcp"].

{ "mcpServers": { "vstgui": { "command": "npx", "args": ["-y", "vstgui-mcp"] } } }

Codex: add this to ~/.codex/config.toml.

[mcp_servers.vstgui]
command = "npx"
args = ["-y", "vstgui-mcp"]

Build

  • Using vstgui, build this gain plugin from my sketch.
  • Build a compressor: threshold, ratio, attack, release and makeup knobs, a gain reduction meter and bypass. Dark with orange accents.

The agent asks a few quick questions, builds while you watch in Figma, then stops and tells you what it couldn't match. Then ask for changes:

  • Make the background a blue to purple gradient.
  • Move the meters 10 px out and make the knob smaller.

Change controls through the agent, not by hand in Figma: controls are rebuilt on export. Hand edits to the panel art and labels are kept.

Export

Say "export" (optionally with a folder). You get:

vstgui-export/<panel>/
  background@2x.png     panel and labels
  knobs/ sliders/ buttons/ meters/ wheels/   one strip per control
  layout.json           position, size, file and frames of every control

Positions are in 1x pixels. Frames stack top to bottom; show frame round(value × (frames − 1)). Figma can't export images past 32,768 px, so a big knob may be saved with fewer frames (at 1x, then with the most frames that fit). The file name shows the frame count, for example gain_112f.png.

Can't do yet

Free boxes and lines, readout boxes, icons on buttons (except power), and gradients with more than two colors. Draw these on the panel in Figma and they're baked into the background.

Troubleshooting

ProblemFix
vstgui not in /mcpRestart your agent in the folder with .mcp.json.
vstgui failedInstall Node.js 18+. On Windows, use the cmd /c setup.
"Port 7417 is in use"Another agent chat has VST GUI Pro. Close it; this one connects by itself.
Dot keeps pulsing amberOpen your agent and check /mcp shows vstgui connected.
PRO dialog appearsAgent mode needs PRO. Unlock it in the plugin.
"Update the plugin" or "update vstgui-mcp"Update the plugin in Figma and restart your agent.

Ask your agent "vstgui help" any time for everything it can do.
